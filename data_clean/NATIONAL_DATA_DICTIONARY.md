# قاموس نسخة المناطق المتاحة

كل صف سجل جهة في ملف إقليمي. مصدر الجوف يحتوي 7 أعمدة دون الرقم الوطني، وبقية المناطق 8 أعمدة. الخلايا المنشورة محفوظة كما وردت؛ عمود الرقم الوطني في نسخة الجوف الموحدة فارغ لأنه غير منشور، ولا يمثل قيمة أصلية كانت موجودة ثم فُقدت. مسافة رأس المعرّف في بعض الملفات وُحّدت بنيوياً، ورأس المصدر الأصلي موثق في الحصر. يشرح `DATA_DICTIONARY.md` الحقول المشتقة المشتركة مع القصيم.

| الحقل | التعريف |
|---|---|
| `region` و`source_region` | منطقة مجموعة المصدر، دون تحقق مستقل من المقر أو نطاق الخدمة |
| `source_slug` | مفتاح ثابت للمنطقة في سجل المصادر |
| `source_dataset_id` | معرّف مجموعة المصدر الرسمية |
| `source_dataset_url` | رابط بطاقة المجموعة التي أتى منها الصف |
| `source_updated_at` | وقت تحديث بطاقة المجموعة كما عرضته المنصة؛ ليس تاريخ ملاحظة الكيان |
| `source_reference_period` | الفترة المرجعية كما عرضت؛ لا تعني ملاحظة كل يوم فيها |
| `source_record` و`source_csv_record` | رقم سجل CSV الأصلي مع رأسه وتنسيقه، يبدأ من 1 |
| `standard_main_group` | True إذا كان التصنيف ضمن G01 إلى G10. U01 وU02 قيم منفصلة غير تخصصية |
| `subcategory_1_comparable` | False لسجلات مكة بسبب تطابق المستويين في المصدر؛ لا تستخدم في مقارنة المستوى الأول |
| `needs_review` | يوجد سبب واحد أو أكثر في سجل المشكلات؛ الصف محفوظ ضمن المجاميع الأساسية |
| `record_key` | مفتاح تتبّع صف بصيغة مصدر:رقم سجل CSV. ليس رقماً وطنياً ولا يثبت هوية الجهة |
| `source_has_national_id` | هل يحتوي المصدر عمود الرقم الوطني أصلاً؟ False للجوف |
| `has_national_id` | هل يحمل السجل رقماً وطنياً منشوراً غير فارغ؟ لا يُولد من اسم أو مفتاح صف |

تتضمن `locality_unit` مدينة ومحافظة ومركز وغير محدد و«غير مذكور في المصدر» للجوف؛ لا تعادل هذه الأنواع جغرافياً. الحالة `named_unit_unstated` تعني اسماً بلا نوع وحدة منشور. `location_label` يتبع الخريطة الإملائية الصريحة، والأصل في عمود «المدينة» باقٍ.

`share_percent` في الجداول الأساسية تستخدم `denominator` لسجلات المصادر: 6,403 في النسخة الحالية. الاسم البرمجي `entity_count` يعني عدد سجلات الجهات، ولا يثبت تفرّد السجلات الـ62 بلا معرّفات عبر المملكة. `share_within_region_percent` يستخدم `region_denominator`. جدول التصنيف الفرعي الأول المقارن يستبعد مكة والقيم الرئيسية غير القياسية، ويعرض مقامه الخاص.

توجد 6,341 أرقام وطنية منشورة فريدة و62 سجلاً بلا معرّف. لا تُحسب الفراغات ضمن العدد الفريد، ولا تُحذف أو تربط سجلات بلا معرّف بناءً على تشابه الأسماء. جدول `identifier_coverage_by_region.csv` يفصل ذلك، ويرتبط سجل المشكلات والتغييرات بـ`record_key` لتجنب خلط سجلات المعرّفات الفارغة.
