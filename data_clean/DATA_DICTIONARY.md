# قاموس نسخة التنظيف

كل صف يمثل كياناً واحداً في ملف المصدر. الترميز UTF-8 مع BOM. تُقرأ المعرّفات نصوصاً. جميع الأعمدة العربية الثمانية التالية محفوظة حرفياً كما نشرت: الرقم الوطني الموحد، اسم الكيان، المدينة، التصنيف النوعي، التصنيف الفرعي الاول، التصنيف الفرعي الثاني، نوع الكيان، جهة الإشراف.

| الحقل المشتق | معناه |
|---|---|
| `source_csv_record` | رقم سجل CSV الأصلي، يبدأ العد من 1؛ ليس بالضرورة رقم سطر نصي إذا احتوى حقل أسطراً داخلية |
| `entity_id` | الرقم الوطني الموحد نصاً بعد توحيد المسافات |
| `entity_name` | اسم الكيان بعد NFC وتوحيد المسافات فقط |
| `region` | القصيم، من سياق مجموعة المصدر وليس عموداً أصلياً |
| `entity_type` | جمعية أهلية أو مؤسسة أهلية، كما في المصدر بعد ضبط المسافات |
| `supervisor` | جهة الإشراف كما نشرت بعد ضبط المسافات؛ لا تحديث تاريخي لأسماء الجهات |
| `locality_name` | اسم الموقع دون بادئة مدينة أو محافظة؛ «أخرى» محفوظة |
| `locality_unit` | مدينة أو محافظة أو غير محدد؛ ليست جميع الوحدات متكافئة جغرافياً |
| `location_label` | اسم الموقع مع نوع الوحدة وبمسافات موحدة |
| `geo_status` | `named`: موقع مسمى؛ `unspecified`: المصدر يقول «أخرى». لا يعني named صحة جغرافية مؤكدة |
| `main_group_code` | G01 إلى G10، رمز مشتق من ترتيب المجموعة المنشور |
| `main_group_name` | الاسم المختصر وفق الرقم والاسم المنشورين |
| `main_description_review` | قيمة منطقية تشير إلى اختلاف وصف البيئة عن عنوانها، دون تغيير الأصل |
| `subcategory_1` | التصنيف الفرعي الأول بعد القواعد الصريحة؛ لا دمج خارج المجموعة الرئيسية |
| `subcategory_2` | التصنيف الفرعي الثاني بعد التصحيحات الإملائية المحددة |
| `needs_review` | موقع غير محدد أو وصف رئيسي متعارض؛ لا يُحذف الصف من الإحصاء |

في جداول التوزيع، `entity_count` عدد سجلات الكيانات، و`share_percent` نسبتهم إلى `denominator` الظاهر في كل صف. جداول `associations_only` تستخدم مقام 533، والبقية الأساسية مقام 562. القيم المستديرة قد لا تجمع إلى 100% تماماً.

راجع `outputs/quality/text_changes.csv` لكل تعديل نصي، و`main_group_mapping_audit.csv` لخريطة المجموعات وعدد تطبيقها، و`review_issues.csv` للحالات التي تحتاج تحققاً.
